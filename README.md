Hi! I'm a integrator with basic experience in JavaScript, Node.js, and Git.

## Why I'm here
This bootcamp is my way to shift careers into DevOps engineering — from zero to job-ready skills.

## 🎯 Goals for these 2 months:
- Master Linux CLI and advanced Git usage
- Understand CI/CD concepts and build pipelines
- Learn Docker, multi-stage builds, and image creation
- Orchestrate containers with Kubernetes and Helm
- Learn Infrastructure as Code (Terraform)
- Deploy apps to the cloud (AWS: EKS, Fargate, etc.)
- Set up observability with Prometheus, Loki, Grafana
- Build an end-to-end DevOps platform from scratch
